# アナログ将棋 v0.3 仕様

更新日：2026-10-26。駒の間隔・移動距離・射線の幅を広げた実装仕様です。

## 目的

将棋の交互手番、駒の種類、駒取り、持ち駒、成りを残し、盤上の位置と移動距離を連続量にします。初期版は1台のブラウザで遊ぶ2人対戦です。

## 座標と当たり判定

- 盤は幅12・高さ12。左上を(0,0)、右下を(12,12)とし、yは下方向に増えます。
- 全駒の当たり判定は半径0.30の円。表示上は将棋駒の形ですが判定は共通です。選択・移動候補・捕獲対象・直前の移動先に表示する円も、この半径に揃えます。危険表示は駒本体の色で区別し、大きな点線の輪は表示しません。
- 駒の中心は x,y ともに0.30〜11.70に置けます。
- 初期配置の駒の並びは通常将棋と同じです。従来の座標を4/3倍にし、中心間隔を1から約1.33へ拡大します。当たり判定の直径は0.6で、隣り合う駒の判定円の隙間は約0.73です。駒の描画サイズは変更しません。
- 先手の前方はy減少方向、後手はy増加方向です。
- 位置は浮動小数点数で保持し、格子への丸めは行いません。表示のみ小数点以下2桁にします。
- 幾何判定の許容誤差は1e-7。ゼロ距離の移動は禁止します。

## 駒の移動

距離はユークリッド距離です。王・金は2.0以内、銀は2.2以内。歩は前方2.0・幅1.2の長方形です。方向の扇形はそれぞれ中心方向から左右22.5度で、境界を含みます。

| 駒 | 許可する移動 |
| --- | --- |
| 王 | 全方向、距離2.0以内 |
| 歩 | 前方2.0・幅1.2の長方形（横だけ・後退は不可） |
| 銀 | 前・左右斜め前・左右斜め後ろの扇形、距離2.2以内 |
| 金 | 前・左右斜め前・左右横・真後ろの扇形、距離2.0以内 |
| 香 | 前方の射線を中心とする幅1.2の帯、距離制限なし |
| 角 | 斜め45度の2本の直線を中心とする幅1.2の帯、距離制限なし |
| 飛 | 縦横2本の直線を中心とする幅1.2の帯、距離制限なし |
| 桂 | 前に3.2・左右に1.6の2点を中心とする半径0.95の円内へ跳躍 |
| 成歩・成香・成桂・成銀 | 金と同じ |
| 馬 | 角の移動と、全方向・距離2.0以内の和集合 |
| 龍 | 飛の移動と、全方向・距離2.0以内の和集合 |

帯の幅は中心線に対して垂直に測ります（片側0.6）。香・角・飛も指定した座標へ直接移動し、射線中央への補正は行いません。敵の駒の周辺も指定した座標のまま判定し、中心への補正は行いません。移動経路は始点と終点を結ぶ直線で、帯の中の好きな点に行けても駒を迂回することはできません。

## 衝突と捕獲

- 全駒共通で、始点と終点を結ぶ中心線が他の駒の円に入らなければ通過できます。移動範囲の一部が遮られても、脇の見通せる位置には移動できます。
- 桂だけは経路の障害物を無視して飛び越えられます。
- 着地点で敵1枚と重なれば捕獲します。味方との重なり・敵2枚との同時重なりは禁止。接するだけでは捕獲しません。
- 桂は着地点のみ衝突判定します。
- 中心間距離が0.6−1e-7未満なら重なりです。捕獲後は指定した座標に止まります。捕獲対象だけを経路の判定から除き、途中の別の駒は飛び越えられません。
- 捕獲した駒は不成の種類で持ち駒になります。捕獲は1手につき1枚です。
- 王そのものを取る操作は禁止します。終局操作は投了です。

王手と危険表示の重なり判定は、移動形状・盤端・駒の円・遮蔽境界と捕獲円の交点および各領域を調べます。粗い盤面格子では判定しません。

## 王手と手番

- 相手駒が王と重なるいずれかの地点へ、盤内・移動範囲・経路・他の駒との重なり条件を満たして到達できる場合を王手とします。
- 移動または打った後に自分の王が王手になる手は禁止します。
- 相手の攻撃判定は移動範囲と経路の判定で行い、攻撃側の自玉の安全判定を再帰的には行いません。
- 王手は画面上で通知し、王も強調表示します。
- 合法な移動・打ちを確定すると手番が交代します。選択・不合法な入力・成り選択のキャンセルでは交代しません。
- 投了すると相手の勝ちで対局を終了し、それ以降の着手を禁止します。

## 成りと打ち

- 先手の敵陣はy≦4、後手はy≧8。境界を含み、中心位置で判定します。
- 成れる種類は歩・香・桂・銀・角・飛です。
- 移動前または移動後に敵陣内なら、成る・成らないを選べます。
- 歩・香は前方への幾何学的な移動余地がなくなる盤端で強制成りします。
- 桂は2つの着地円と盤内の中心座標領域に共通部分がなくなる場合、強制成りします。
- 強制成り・打ち禁止の「次に動けるか」は駒の配置による一時的な障害を考慮せず、幾何学的な移動余地で判定します。
- 持ち駒は、盤内で他の駒と重ならない任意の座標に不成で打てます。
- 次の移動余地がない位置への打ち、自玉への王手を残す打ちは禁止します。
- 二歩、打ち歩詰めの禁止は採用していません。

## 移動中のプレビュー

- 盤上の駒も候補位置に駒本体が追従します。元の駒と捕獲対象は薄く残します。
- 合法な候補位置には、移動・捕獲後の盤面を仮に作り、その駒の次の移動範囲を青で表示します。強制成りは反映し、任意成りは未選択のため不成として表示します。
- 移動・打ちの合法な候補位置では、配置後に取られる可能性のある持ち上げ中の駒を紫色の縁で強調し、その駒が次に取れる敵駒を橙で強調します。敵の王への王手は赤で表示します。「危険」の自分・相手ボタンに連動し、自玉を王手にさらす捕獲は除外します。今の手で取られる駒は配置後の判定から除きます。
- 不合法な候補位置では駒を赤く表示し、移動後の範囲は表示しません。確定前に実際の局面・棋譜・持ち駒は変化しません。
- 選択解除・盤外への移動・確定時にはプレビューが消え、元の駒の表示を戻します。

## 持ち駒の配置プレビュー

- 持ち駒の選択中は、打てる地点を薄緑の領域で表示します。盤端・重なり・行き所のない駒・王手の解消を反映します。
- 薄緑の領域は通常240×240、王手中は72×72のサンプルで描画する目安です。候補位置と確定時は連続座標で厳密に判定します。
- 合法な候補位置に置く駒の文字と、配置後の移動範囲を青でプレビューします。配置後の障害物も反映しますが、自玉への王手の制限は移動先で判定する目安です。
- マウス・タッチ・キーボードに追従し、解除や手番交代で消えます。プレビューは盤面や持ち駒を変更しません。

## 全駒の範囲と危険表示

- 「自分の範囲」は現在の手番側、「相手の範囲」は反対側です。手番交代に追従し、青・橙で両方同時に表示できます。
- 全駒の範囲は移動形状・経路・着地点の重なりを反映した目安です。自玉の王手による制限は着手候補で判定します。
- 相手が次の一手で合法的に取れる駒を、手番側は青、反対側は橙の縁で強調します。それぞれの「危険」ボタンで独立して表示を切り替えられます。王手の表示はオフでも残ります。攻撃側の自玉が王手になる捕獲は除きます。王は既存の王手判定に従います。持ち駒からの将来の攻撃は含めません。

## 操作と状態保存

- マウス・タッチの選択→移動先指定、ドラッグ、キーボード操作を用意します。
- 選択時は幾何学的な範囲を表示します。全駒で障害物の影と着地点で重なる領域を範囲表示から除き、取れる駒を強調します。障害物や自玉への王手を含む合法性は移動先のプレビューで別途表示します。
- 持ち駒、棋譜、直前の移動元と移動先、選択解除、盤の180度反転を用意します。
- 対局の初期化と投了は確認ダイアログを表示します。
- 最大100操作の待ったが可能です。棋譜は全件保存し、画面には直近100手を表示します。
- 状態はlocalStorageへ保存します。読めない保存データは新規対局として開始します。保存失敗時は画面に通知します。v0.2は別の保存キーを使用して新規対局として開始し、v0.1の保存データは上書きしません。
- 盤を反転しても論理座標・先後・棋譜は変わりません。

## 配信

依存ライブラリなしのES ModulesとSVGで実装。HTML/CSS/JS/SVGの静的配信で動作し、Cloudflare Pages等へ配置できます。ゲーム用のサーバー、ユーザー登録、通信対戦のAPIはありません。
