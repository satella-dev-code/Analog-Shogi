# アナログ将棋 v0.3 仕様

更新日：2026-10-26。駒の間隔・移動距離・射線の幅を広げた実装仕様です。

## 目的

将棋の交互手番、駒の種類、駒取り、持ち駒、成りを残し、盤上の位置と移動距離を連続量にします。初期版は1台のブラウザで遊ぶ2人対戦です。

## 座標と当たり判定

- 盤は幅10.8・高さ10.8。左上を(0,0)、右下を(10.8,10.8)とし、yは下方向に増えます。初期配置は左右・前後の間隔1.2、外周の駒の中心から盤端まで0.6です。
- 全駒の当たり判定は半径0.30の円。表示上は将棋駒の形ですが判定は共通です。選択・移動候補・捕獲対象・直前の移動先に表示する円も、この半径に揃えます。危険表示は駒本体の色で区別し、大きな点線の輪は表示しません。
- 駒の中心は x,y ともに0.30〜10.50に置けます。
- 初期配置の駒の並びは通常将棋と同じです。左右・前後の中心間隔は1.2です。当たり判定の直径は0.6で、隣り合う駒の判定円の隙間は0.6です。
- 先手の前方はy減少方向、後手はy増加方向です。
- 位置は浮動小数点数で保持し、格子への丸めは行いません。表示のみ小数点以下2桁にします。
- 幾何判定の許容誤差は1e-7。ゼロ距離の移動は禁止します。

## 駒の移動

距離はユークリッド距離です。王・金は2.0以内、銀は2.2以内。歩は前方2.0・幅1.2の長方形です。方向の扇形はそれぞれ中心方向から左右22.5度で、境界を含みます。

| 駒 | 許可する移動 |
| --- | --- |
| 王 | 全方向、距離2.0以内 |
| 歩 | 前方2.0・幅1.2の長方形（横だけ・後退は不可） |
| 銀 | 前・左右斜め前・左右斜め後ろの扇形、距離2.2以内 |
| 金 | 前・左右斜め前・左右横・真後ろの扇形、距離2.0以内 |
| 香 | 前方の射線を中心とする幅1.2の帯、距離制限なし |
| 角 | 斜め45度の2本の直線を中心とする幅1.2の帯、距離制限なし |
| 飛 | 縦横2本の直線を中心とする幅1.2の帯、距離制限なし |
| 桂 | 前に3.2・左右に1.6の2点を中心とする半径0.95の円内へ跳躍 |
| 成歩・成香・成桂・成銀 | 金と同じ |
| 馬 | 角の移動と、全方向・距離2.0以内の和集合 |
| 龍 | 飛の移動と、全方向・距離2.0以内の和集合 |

帯の幅は中心線に対して垂直に測ります（片側0.6）。香・角・飛も指定した座標へ直接移動し、射線中央への補正は行いません。敵の駒の周辺も指定した座標のまま判定し、中心への補正は行いません。移動経路は始点と終点を結ぶ直線で、帯の中の好きな点に行けても駒を迂回することはできません。

## 衝突と捕獲

「通過判定」で「スタンダードモード」「ワイルドモード」「飛車制限モード（実験）」を選べます。既定はスタンダード。ワイルドモードは、経路と他の駒の中心との距離が0.3−1e-7以上なら通れます。飛車制限モードは等間隔1.2の初期配置で、飛車・龍の経路の遮蔽半径を0.6、その他をワイルドと同じ0.3にします。角・馬の斜めの帯は全幅1.2です。角は初手で歩の列を越えられますが、遮蔽円同士の接点を通る経路があるため飛車の初手王手を完全には禁止しません。着地点の重なり判定・捕獲は円、桂の跳躍は全モード共通です。旧菱形・旧配置調整・旧角拡張モードは過去の棋譜・保存状態の互換用に内部に残します。進行中の変更は確認後に新規対局を開始し、設定は自動保存・棋譜・CPU・移動範囲表示に共通で適用します。

- スタンダードモードでは、桂以外の全駒は移動する円と他の駒の円が途中でも重ならない経路を通ります。中心線と障害物の中心の距離は0.6−1e-7以上が必要です。移動範囲の一部が遮られても、円が通れる幅のある脇の位置には移動できます。
- 桂だけは経路の障害物を無視して飛び越えられます。
- 着地点で敵1枚と重なれば捕獲します。味方との重なり・敵2枚との同時重なりは禁止。接するだけでは捕獲しません。
- 桂は着地点のみ衝突判定します。
- 中心間距離が0.6−1e-7未満なら重なりです。捕獲後は指定した座標に止まります。捕獲対象だけを経路の判定から除き、途中の別の駒は飛び越えられません。
- 捕獲した駒は不成の種類で持ち駒になります。捕獲は1手につき1枚です。
- 王そのものを取る操作は禁止します。終局操作は投了です。

王手と危険表示の重なり判定は、移動形状・盤端・駒の円・遮蔽境界と捕獲円の交点および各領域を調べます。粗い盤面格子では判定しません。

## 王手と手番

- 相手駒が王と重なるいずれかの地点へ、盤内・移動範囲・経路・他の駒との重なり条件を満たして到達できる場合を王手とします。
- 移動または打った後に自分の王が王手になる手は禁止します。
- 相手の攻撃判定は移動範囲と経路の判定で行い、攻撃側の自玉の安全判定を再帰的には行いません。
- 王手は画面上で通知し、王も強調表示します。
- 王の移動範囲も連続した図形で計算します。捕獲しない場合と各敵駒を捕獲する場合に分け、それぞれの移動・障害物条件を満たす領域から、移動後の敵の攻撃が届く領域を差し引きます。敵の攻撃端点を直径0.6ぶん広げて王の中心への攻撃領域を求め、全駒範囲では各王の手番を仮定します。確定時は既存の連続座標の合法手判定を使います。
- 合法な移動・打ちを確定すると手番が交代します。選択・不合法な入力・成り選択のキャンセルでは交代しません。
- 投了すると相手の勝ちで対局を終了し、それ以降の着手を禁止します。

## 成りと打ち

- 先手の敵陣はy≦4、後手はy≧8。境界を含み、中心位置で判定します。
- 成れる種類は歩・香・桂・銀・角・飛です。
- 移動前または移動後に敵陣内なら、成る・成らないを選べます。
- 歩・香は前方への幾何学的な移動余地がなくなる盤端で強制成りします。
- 桂は2つの着地円と盤内の中心座標領域に共通部分がなくなる場合、強制成りします。
- 強制成り・打ち禁止の「次に動けるか」は駒の配置による一時的な障害を考慮せず、幾何学的な移動余地で判定します。
- 持ち駒は、盤内で他の駒と重ならない任意の座標に不成で打てます。
- 次の移動余地がない位置への打ち、自玉への王手を残す打ちは禁止します。
- 二歩は、自分の不成の歩の中心から左右0.3以内（境界を含む）で、盤の上下端まで続く帯への歩打ちを禁止します。打つ歩の中心で判定します。相手の歩・成った歩は数えず、通常の歩の移動には適用しません。打ち歩詰めの禁止は採用していません。

## 移動中のプレビュー

- 盤上の駒も候補位置に駒本体が追従します。元の駒と捕獲対象は薄く残します。
- 合法な候補位置には、移動・捕獲後の盤面を仮に作り、その駒の当たり判定が届く範囲を薄緑で表示します。元の長方形・扇形・円から移動領域を作り、盤端・経路・着地点の障害物を差し引いた後、自分の駒の半径0.3で丸いオフセットを計算します。敵駒の中心位置の範囲ではありません。格子化・事後の輪郭平滑化は使いません。円弧の数値近似誤差はワールド座標0.001以下、整数座標の精度は0.000001です。王は合法な移動領域から計算します。強制成りは反映し、任意成りは未選択のため不成として表示します。
- 移動・打ちの合法な候補位置では、配置後に取られる可能性のある持ち上げ中の駒を紫色の縁で強調し、その駒が次に取れる敵駒を緑で強調します。敵の王への王手は赤で表示します。「危険」の先手・後手ボタンに連動し、自玉を王手にさらす捕獲は除外します。今の手で取られる駒は配置後の判定から除きます。
- 不合法な候補位置では駒を赤く表示し、移動後の範囲は表示しません。確定前に実際の局面・棋譜・持ち駒は変化しません。
- 選択解除・盤外への移動・確定時にはプレビューが消え、元の駒の表示を戻します。

## 持ち駒の配置プレビュー

- 持ち駒の選択中は、打てる地点を薄い青の領域で表示します。盤端・重なり・行き所のない駒・王手の解消を反映します。
- 配置可能な領域は通常240×240、王手中は72×72のサンプルで描画する目安です。候補位置と確定時は連続座標で厳密に判定します。
- 合法な候補位置に置く駒の文字と、配置後の自分の駒の当たり判定が届く範囲の目安を薄緑でプレビューします。配置後の障害物も反映しますが、自玉への王手の制限は移動先で判定する目安です。
- マウス・タッチ・キーボードに追従し、解除や手番交代で消えます。プレビューは盤面や持ち駒を変更しません。

## 全駒の範囲と危険表示

- 「先手の範囲」は先手、「後手の範囲」は後手に固定します。青・橙で両方同時に表示できます。
- 全駒の範囲は移動形状・経路・着地点の重なりと自玉の王手による制限を反映します。王以外のピン・王手回避の境界は描画用メッシュで近似します。
- 相手が次の一手で合法的に取れる駒を、先手は青、後手は橙の縁で強調します。それぞれの「危険」ボタンで独立して表示を切り替えられます。王手の表示はオフでも残ります。攻撃側の自玉が王手になる捕獲は除きます。王は既存の王手判定に従います。持ち駒からの将来の攻撃は含めません。

## 操作と状態保存

- マウス・タッチの選択→移動先指定、ドラッグ、キーボード操作を用意します。
- 選択時は配置可能範囲を表示します。障害物の影、重なり、自玉への王手で置けない領域を除き、取れる駒を強調します。最終的な合法性は移動先の連続座標で検証します。
- 持ち駒、棋譜、直前の移動元と移動先、選択解除、盤の180度反転を用意します。
- 対局の初期化と投了は確認ダイアログを表示します。
- 最大100操作の待ったが可能です。棋譜は全件保存し、画面には直近100手を表示します。
- 状態はlocalStorageへ保存します。読めない保存データは新規対局として開始します。保存失敗時は画面に通知します。v0.2は別の保存キーを使用して新規対局として開始し、v0.1の保存データは上書きしません。
- 盤を反転しても論理座標・先後・棋譜は変わりません。

## 配信

ES ModulesとSVGで実装。図形の合成・差分・丸いオフセットには同梱のclipper-lib 6.4.2を使用し、著作権・ライセンス表示をpublic/vendor/に収録します。外部CDNへの接続は不要です。HTML/CSS/JS/SVGの静的配信で動作し、Cloudflare Pages等へ配置できます。ゲーム用のサーバー、ユーザー登録、通信対戦のAPIはありません。

## 棋譜とリプレイ

「棋譜」欄から、一手ずつの送り・戻し、最初・最後への移動、1秒間隔の自動再生を利用できます。棋譜の各行を押すと、その着手後の局面を表示します。再生中は着手・待った・投了・新規対局を無効にし、「対局に戻る」で再生前の局面を復元します。

棋譜は連続座標、成り、駒取り、持ち駒、投了を含む局面差分として自動保存します。JSONファイルとして保存・読み込みができ、読み込みは再生専用で現在の対局を上書きしません。待ったをすると棋譜の末尾も取り消します。旧保存データは残っている最大100操作分から移行し、途中からの記録であることを表示します。


## スマホのドラッグ補助

盤と駒の文字選択・長押しメニューを抑制します。スマホ幅（短辺700px以下）のタッチ操作では、駒・持ち駒の配置候補をドラッグ中に約2.4倍で拡大表示します。拡大鏡は盤の見えている四隅から指に重ならない位置を選び、安全に離れている間は位置を固定します。指を離す、操作を取り消す、画面サイズが変わると非表示になります。マウス操作やリプレイ中には表示しません。


## 配置可能範囲と表示対象

全駒の範囲・危険表示は先手（青）／後手（橙）に固定し、手番や盤の反転で対象を入れ替えません。選択した駒の配置可能範囲は青で表示します。王は従来の連続図形による王手除外を用い、その他の駒も王手放置やピンを考慮して除外します。王以外の王手回避・ピンに関わる領域のみ0.04単位の保守的なメッシュで輪郭を近似します。境界付近で表示と最終判定に微小な差が生じることがあり、配置可否は連続座標のエンジン検証を優先します。配置に失敗した場合は選択を解除し、理由を表示します。薄緑は配置後の幾何学的な到達範囲の予測で、未来の着手を保証する表示ではありません。

## 簡易CPU対戦

対戦モードは「2人対戦」と「CPU対戦（自分は先手）」を途中でも切り替えられます。CPUは後手を担当します。Web Worker内で候補地点と駒取りを探索し、駒の価値・成り・前進・王手・取られる危険を評価します。探索は近似ですが、着手は通常と同じルールで再検証します。詰み判定や強さの保証はありません。手が見つからない・処理に失敗する・15秒を超える場合は終局にせず2人対戦へ戻します。

CPU対戦の待ったは、CPUの応手も取り消し自分の手番まで戻ります。リプレイ・待った・新規対局・モード切り替え時には古い探索を中止し、古い結果が局面に適用されないようにします。モードは対局とともに自動保存します。

## CPU同士の観戦

「CPU vs CPU」モードでは、先手・後手ともCPUが指します。各手の探索開始前に900msの間隔を置き、観戦中も一時停止・再開できます。待ったは一手戻して一時停止し、再開するまで局面を保持します。観戦中は人間による着手・投了を受け付けません。棋譜再生・確認ダイアログ・モード変更時は既存の探索キャンセルを適用し、古い応手を破棄します。モードと停止状態は自動保存します。新規対局・モード変更で自動対戦を開始します。


## CPUの手の多様性

CPUは候補を絞り込む際に評価が近い位置の順序へ小さな乱数を加え、評価後は最良手から40点以内の候補のみを対象に、評価の高い手ほど選ばれやすい重み付き抽選を行います。駒取り・成り・取られる危険などの評価そのものは維持します。人間とのCPU対戦・CPU同士の観戦の両方に適用します。明確な最善手がある場合や偶然により、同じ手になることもあります。棋譜には抽選結果の正確な座標を保存するため、リプレイは従来どおり同じ局面を再現します。

## 英語版の駒

五角形の駒の形を保ち、英語版では中央を独自のSVGシルエットに切り替えます。王・飛・角・桂・歩はチェス風、香は槍、金は星入りの盾、銀は菱形入りの縁取りの盾です。チェス風の駒は台座の幅と高さを揃え、桂は曲線の馬の横顔、角は切れ込みのある僧帽で区別します。成りは元の絵に＋を付けます。盤上・持ち駒・移動中の駒・拡大鏡で共通の絵柄を使い、選択時は持ち駒欄の右端に英語名を表示します。日本語版は漢字を維持します。

スマホでは駒をタップして選択し、別の場所をタップして移動できます。ドラッグも併用でき、指の揺れによる誤移動を防ぐため12 CSS pxを超えて動かすまではドラッグと扱いません。拡大鏡もドラッグ開始後だけ表示します。

持ち駒欄から盤上への直接ドラッグ配置にも対応します。持ち駒を短くタップした場合は選択だけを行い、続けて盤上をタップできます。ドラッグ中は盤上の駒と共通の配置予測・危険表示・タッチ拡大鏡を使います。盤外や配置不可の地点で離した場合は駒を消費せず選択解除し、キャンセル時も残数を維持します。
